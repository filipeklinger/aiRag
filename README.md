# AiRag
Ai Rag in dotnet csharp

This is A POC (Proof of Concept) for a simple AI Rag (Retrieval-Augmented Generation) system using the Ollama API.

## Objetives

The goal is to test if a RAG system can improve the accuracy of the answers provided by the AI model through the use of a vector database with exemplary data of input <> output pairs.
